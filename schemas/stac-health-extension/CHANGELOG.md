# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com),
and this project adheres to [Semantic Versioning](https://semver.org).

## - 2026-11-23

### Added
- Initiales JSON-Schema (`schema.json`) mit Unterstützung für Collections und Items.
- ISO-19115-konforme Felder `health:status`, `health:update_frequency` und `health:representation_type`.
- Bedingte Validierung (`if/then`) für `health:spatial_resolution` und `health:temporal_resolution`.
- Optionale/empfohlende Felder `health:scale` und `health:format`.
- Beispiel-Dateien (`collection.json`, `item.json`), `package.json` und Dokumentation (`README.md`).
